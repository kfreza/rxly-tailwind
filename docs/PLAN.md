# Rxly Landing Page — Build Plan

Companion to [BRIEF.md](BRIEF.md). **Status (2026-11-23): all 8 phases done.** Open items are under "Waiting on" at the bottom.

## Stack

| Concern | Choice | Notes |
|---|---|---|
| Build tool | Vite 8 | `vite.config.js` has a tiny `<!-- @include … -->` plugin, so each section lives in its own file |
| CSS | Tailwind CSS v4 (`@tailwindcss/vite`) | Tokens in `src/styles/app.css` (`@theme`), patterns in `components.css` |
| JS | Vanilla ES modules | nav, tabs, accordion, pricing, i18n, reveal, scenes |
| Fonts | Plus Jakarta Sans + Noto Sans Bengali (variable, self-hosted via `@fontsource-variable`) | Bangla loads only when Bangla glyphs (or ৳) are on the page |
| Animations | Figma motion → CSS, generated by `scripts/build-motion.mjs` | Loaded on demand; off when `prefers-reduced-motion` |
| i18n | `data-i18n` keys; `src/i18n/en.json` + `bn.json` generated by `scripts/extract-i18n.mjs` | Bangla mainly from the **official Rxly app strings** |
| QA | `puppeteer-core` + local Chrome | `npm run qa`, `npm run qa:anim`, `npm run shot` |

## Breakpoints

| Name | Width | Layout |
|---|---|---|
| mobile | < 768 | single column |
| `md` tablet | 768–1199 | 2 columns, hamburger menu |
| `desk` | **≥ 1200** | **same layout as Figma**; content max 1440, centred |
| `wide` | ≥ 1440 | Figma's large offsets (hero floating cards, FAQ dome) |

## Folder structure

```
index.html                  page shell (includes sections)
src/
  sections/*.html           nav, hero, features, screens, how, bangladesh, pricing, faq, cta, footer
  scenes/*.html             3 animated Figma scenes (416×240 stage, scaled by js/scenes.js)
  partials/head-meta.html   GENERATED (scripts/build-seo.mjs)
  styles/app.css            tokens, base, Bangla line-height
  styles/components.css     .btn, .pill, .mark, cards, tabs, plans, FAQ …
  styles/motion.css         GENERATED (scripts/build-motion.mjs), lazy-loaded
  js/*.js                   behaviour
  i18n/en.json, bn.json     GENERATED; edit bn.manual.json for Bangla overrides
public/images/              optimised WebP/SVG (served)
design/
  motion/features.json      Figma motion export (source for motion.css)
  i18n/bn-official.json     official Rxly Bangla strings (from the live app)
  source-images/            original PNG/JPG exports (source for WebP)
scripts/                    build + QA tools (see package.json)
docs/                       BRIEF.md, PLAN.md
```

## npm scripts

| Command | What it does |
|---|---|
| `npm run dev` | dev server (http://localhost:5173) |
| `npm run build` | i18n → SEO meta → production build in `dist/` |
| `npm run preview` | serve `dist/` on http://localhost:4173 |
| `npm run images` | convert new PNG/JPG in `public/images` to WebP (originals → `design/source-images`) |
| `npm run motion` | regenerate `motion.css` from `design/motion/*.json` |
| `npm run og` | regenerate `public/og-image.png` (preview must be running) |
| `npm run qa` | interaction tests at 390 / 834 / 1280 / 1920 (preview must be running) |
| `npm run qa:anim` | check that scene animations load and play |
| `npm run shot -- 390 out.png` | full-page screenshot at a given width (`--lang=bn`, `--motion`) |
