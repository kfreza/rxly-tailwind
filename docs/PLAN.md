# Rxly Landing Page — Build Plan

Companion to [BRIEF.md](BRIEF.md). **Status (2026-11-28): all 8 phases done, plus the polish pass below (motion, hover effects, Figma videos rebuilt in code).** Open items are under "Waiting on" at the bottom.

## Stack

| Concern | Choice | Notes |
|---|---|---|
| Build tool | Vite 8 | `vite.config.js` has a tiny `<!-- @include … -->` plugin, so each section lives in its own file |
| CSS | Tailwind CSS v4 (`@tailwindcss/vite`) | Tokens in `src/styles/app.css` (`@theme`), patterns in `components.css` |
| JS | Vanilla ES modules | nav (+ active-section underline), tabs (sliding pill), accordion, pricing, pin-cards, scatter, reveal, i18n, title-motion, dot-globe, bd-ring |
| Fonts | Plus Jakarta Sans + Noto Sans Bengali (variable, self-hosted via `@fontsource-variable`) | Bangla loads only when Bangla glyphs (or ৳) are on the page |
| Animations | Team SVGs (`scene-queue/page/brand.svg`), CSS/SVG motion, two canvas/JS pieces | Team SVGs are used as plain `<img>`; `scene-brand.svg` colours were changed to the accent blue (mint kept). Everything respects reduced motion |
| i18n | `data-i18n` keys; `src/i18n/en.json` + `bn.json` generated by `scripts/extract-i18n.mjs` | Bangla mainly from the **official Rxly app strings** |
| QA | `puppeteer-core` + local Chrome | `npm run qa`, `npm run qa:scatter`, `npm run shot` |

## Breakpoints

| Name | Width | Layout |
|---|---|---|
| mobile | < 768 | single column |
| `md` tablet | 768–1199 | 2 columns, hamburger menu |
| `desk` | **≥ 1200** | **same layout as Figma**; content max 1440, centred |
| `wide` | ≥ 1440 | Figma's large offsets (hero floating cards, FAQ dome) |

## Folder structure

```
index.html                  page shell (includes sections)
src/
  sections/*.html           nav, hero, features, screens, how, bangladesh, pricing, faq, cta, footer
  partials/head-meta.html   GENERATED (scripts/build-seo.mjs)
  styles/app.css            tokens, base, Bangla line-height
  styles/components.css     .btn, .pill, .mark, cards, tabs, plans, FAQ …
  js/*.js                   behaviour
  i18n/en.json, bn.json     GENERATED; edit bn.manual.json for Bangla overrides
public/images/              ALL served images in one flat folder, named <section>-<what>.<ext>
                            (hero-, feature-, scene-queue/page/brand, screens-, how-, bd-,
                            pricing-, faq-, cta-, icon-, logo*)
                            (title underlines are inline SVG in the section HTML, not image files)
design/
  i18n/bn-official.json     official Rxly Bangla strings (from the live app)
  source-images/            original PNG/JPG exports, same flat names (source for WebP)
scripts/                    build + QA tools (see package.json)
docs/                       BRIEF.md, PLAN.md
```

## npm scripts

| Command | What it does |
|---|---|
| `npm run dev` | dev server (http://localhost:5173) |
| `npm run build` | i18n → SEO meta → production build in `dist/` |
| `npm run preview` | serve `dist/` on http://localhost:4173 |
| `npm run images` | convert new PNG/JPG in `public/images` to WebP (originals → `design/source-images`) |
| `npm run og` | regenerate `public/og-image.png` (preview must be running) |
| `npm run qa` | interaction tests at 390 / 834 / 1280 / 1920 (preview must be running) |
| `npm run qa:scatter` | capture the How it works scatter at 3 scroll positions |
| `npm run shot -- 390 out.png` | screenshot at a given width (`--lang=bn`, `--motion`, `--el=#id`, `--wait=ms`) |

### Phase 4: interactions ✅
- [x] Mobile menu (focus trap, Esc, scroll lock, closes at ≥1200)
- [x] ARIA tabs with arrow/Home/End keys; the tab strip scrolls horizontally on mobile. A blue pill slides to the selected tab; the new panel fades up in parts (title, copy, screenshot; the two phones one after another) while the frame eases to the new height
- [x] FAQ accordion (one open at a time, smooth grid-rows open/close, accent line draws left → right). The block reserves the height of the longest answer, so nothing below moves when you switch questions (`js/accordion.js`)
- [x] Monthly/Yearly pricing (CSS-driven; both prices are translatable text)
- [x] Pricing 3D cards (`js/pin-cards.js`; motion modelled on the testimonials section of norio-nextjs-dev.pages.dev, which uses GSAP ScrollTrigger; re-implemented without a library). Always real Figma size and spacing (120px above the pill, 121px below the cards) — nothing is scaled. Desktop ≥1200px with motion allowed: if the window fits the whole section under the nav (~1,180px tall), the stage (background, heading, cards) pins (`.is-pinned`, 140vh spacer) and the cards rise one after another from below into their slots (rotateX 58°, rotateY −32° / 0° / +32°, z −180px, scale 0.82, 0.35s smoothing); otherwise the section scrolls normally and the same animation plays, staggered, as the cards move from 95% to 45% of the screen. Below 1200px: lighter tilt. Reduced motion: static.
- [x] "How it works" scroll-scatter (`js/scatter.js`): from 1200px the 3 step cards start in Figma's fanned stack (−5° / 0° / +5°, step 3 on top) and spread into a 3-card row as you scroll (grid top 80% → 20% of the viewport). Below 1200px and with reduced motion they show as a plain stack/row. Check with `npm run qa:scatter`
- [x] EN ⇄ বাংলা switch, remembered in `localStorage`, no flash on reload
- [x] Section title entrances (`js/title-motion.js` + `styles/title-motion.css`, approved draft https://claude.ai/artifact/9zGXSS5L9dAfvB8Yz7LkpW): a different animation per title — hero rise from mask (on load), What it does blur-in, Screens drop + wipe, How it works letter wave + dusk sweep, Bangladesh lines converge, Pricing 3D word flip, FAQ line rise + pen underline, CTA tracking tighten — each ending with the blue word's underline drawing left → right. Plays once at 88% of the screen (or when scrolled past, so nothing is left hidden). Split inside the translatable spans, by word in Bangla. Static with reduced motion.
- [x] Hover effects (approved demo https://claude.ai/artifact/AjtrzY8TcYdcmJ9JFsEgZQ), all also on keyboard focus, no movement with reduced motion: primary buttons shine + arrow; outline fills in from the left and exits right; dark plan buttons turn blue on card hover and behave like the primary on button hover; CTA rises with a white halo; header links get a centre-out underline that stays on the active section (`js/nav.js` scroll spy); footer links darken with a blue underline; unselected tabs get a pale blue hint; billing option text turns blue; FAQ question turns blue and its icon fills solid blue (inline SVG, colour only, no scale, so it never shifts); language switch and menu buttons turn pale blue, the globe spins
- [x] CTA title animates letter positions with transforms (not letter-spacing), so the lines never re-wrap and nothing below shifts
- [x] Scroll-in reveals (not on the hero); the 3 "What it does" illustrations are the team's animated SVGs (`scene-queue.svg`, `scene-page.svg`, `scene-brand.svg`). Note: `scene-queue.svg` uses SMIL animation, so it keeps animating for reduced-motion users (the other two stop)
